Quick reference: AH vs. ESP, Tunnel vs. Transport

AH — Authentication Header

Provides integrity and origin authentication. Proves the packet wasn't altered and really came from who it claims — but the data itself stays readable.

ESP — Encapsulating Security Payload

Provides integrity and authentication like AH, plus optional encryption. When encryption is enabled, the protected data becomes unreadable to anyone without the key.

Tunnel mode

  • Wraps the entire original packet — header and all — inside a new IP packet.
  • Used gateway-to-gateway, server-to-gateway, or server-to-server.
  • Hides internal addressing from outside observers; better NAT traversal; more overhead.

Transport mode

  • Keeps the original IP header in place; only the payload is protected.
  • Used host-to-host, workstation-to-gateway.
  • Lower overhead, but the original source/destination stay visible and NAT traversal is harder.
