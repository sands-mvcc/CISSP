COBIT 2019 / Performance Monitoring & Reporting ISACA Framework Reference
Command / Directive Parameters / Options Description & Objective Context Execution Example
cobit-domain --align=EDM|APO|BAI|DSS|MEA Executes governance/management domain scope. Focuses on Evaluate, Direct, & Monitor (EDM) or Monitor, Evaluate, & Assess (MEA) for performance. cobit-domain --align=MEA
mea-monitor --scope=perf|conformance --target=kpi Monitors, evaluates, and assesses IT performance and conformance against enterprise strategic metrics. mea-monitor --scope=perf --target=kpi
cobit-capability --level=0..5 --domain=[domain_id] Assesses processes against CMMI-aligned Capability Levels (Level 0: Incomplete to Level 5: Optimizing). cobit-capability --level=3 --domain=MEA01
cobit-racie --role=[title] --assign=R|A|C|I Sets structural governance accountability matrix: Responsible, Accountable, Consulted, Informed. cobit-racie --role=CIO --assign=A
cobit-design --df=[1..10] --weight=[high|med|low] Applies COBIT Design Factors (e.g., Threat Landscape, Enterprise Strategy) to tailor governance system. cobit-design --df=4 --weight=high
cobit-scorecard --metric=kbi|kpi --interval=qtr Generates Balanced Scorecard reporting output mapping IT operational performance directly to business goals. cobit-scorecard --metric=kpi --interval=qtr
SOC 1 / SOC 2 (Trust Services Criteria) AICPA Assurance Controls
Command / Directive Parameters / Options Description & Objective Context Execution Example
soc2-tsc --criteria=CC|availability|confidentiality Evaluates system against Trust Services Criteria (Common Criteria, Security, Availability, Confidentiality, Processing Integrity, Privacy). soc2-tsc --criteria=CC --audit
soc-report --type=1|2 --period=[months] Specifies audit scope: Type 1 (Design suitability at point in time) vs Type 2 (Operating effectiveness over minimum 6 mos). soc-report --type=2 --period=12
soc-control --id=[cc_id] --test=design|operating Executes testing procedure for specific internal control implementation and logging evidence. soc-control --id=CC6.1 --test=operating
soc-evidence --collect=[logs|diffs|approvals] Pulls automated change management and access control tracking outputs for independent audit sampling. soc-evidence --collect=approvals
ISO 9001:2015 (Quality Management System) Quality Control & Continual Improvement
Command / Directive Parameters / Options Description & Objective Context Execution Example
pdca-cycle --phase=plan|do|check|act Executes Plan-Do-Check-Act iterative management method for continuous quality process improvement. pdca-cycle --phase=check
iso-audit --scope=internal|external --clause=[4..10] Performs audit validation against ISO 9001 clauses (e.g., Clause 9: Performance Evaluation, Clause 10: Improvement). iso-audit --scope=internal --clause=9
iso-capa --issue=[id] --action=corrective|preventive Logs Corrective and Preventive Action (CAPA) tracking sequence to remediate identified non-conformances. iso-capa --issue=NC-402 --action=corrective
iso-qms-metric --target=quality_policy --eval=pass|fail Measures organizational process outputs against established quality management objectives and policy targets. iso-qms-metric --target=policy --eval
