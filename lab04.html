Domain 4: Communication and Network Security

Learning Objectives

  • Design secure network architecture using segmentation and defense in depth.
  • Map data flows through the OSI and TCP/IP models.
  • Select and position network security components (Firewalls, IDS/IPS).
  • Implement secure communication protocols (TLS, IPSec, SSH).
  • Secure wireless and remote access environments.
  • Identify and mitigate common network attacks.

Key Terms & Concepts

Network Segmentation
Dividing a physical network into smaller logical sub-networks to limit attack surfaces.
DMZ
A buffered sub-network between the untrusted internet and the trusted internal network.
Zero Trust
An architectural model based on 'never trust, always verify'.
IPS
Inline network appliance that inspects and blocks malicious traffic in real-time.
